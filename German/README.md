# Deutsch Lernen — Application d'apprentissage de l'allemand

Application web statique pour apprendre l'allemand. Cliquez sur les mots pour afficher leur traduction, leur déclinaison et leur conjugaison.

## Structure

```
German/
├── index.html          — Application principale (SPA)
├── netlify.toml        — Configuration Netlify
└── data/
    ├── vocabulary.json — 300 mots (A1/A2/B1) avec déclinaisons et conjugaisons
    └── texts.json      — 15 textes annotés (Actualités / Histoires / Dialogues)
```

## Fonctionnalités

- Textes courts en allemand par catégorie et niveau (A1 → B1)
- Clic sur un mot → traduction japonaise + française
- Tableaux de conjugaison pour les verbes
- Tableaux de déclinaison pour les noms et adjectifs
- Interface en français
